## 🚀 快速开始

### 1. 启动实时协作
```
命令面板 (Ctrl+Shift+P) → "Live Code Viewer: Start Hosting"
```

### 2. 查看参与者状态
```
命令面板 → "Live Code Viewer: Show Participant Panel"
```

### 3. 监控性能指标
```
命令面板 → "Live Code Viewer: Show Performance Panel"
```

### 4. 查看错误报告
```
命令面板 → "Live Code Viewer: Show Error Report"
```

### 5. 快捷键帮助
```
命令面板 → "Live Code Viewer: Show Shortcut Help"
```

## ⌨️ 快捷键系统

### 默认快捷键

**协作功能**:
- `Ctrl+Shift+L C` - 创建房间
- `Ctrl+Shift+L J` - 加入房间
- `Ctrl+Shift+L P` - 显示参与者面板
- `Ctrl+Shift+L S` - 显示性能监控

**状态管理**:
- `Ctrl+Shift+L R` - 显示房间面板
- `Ctrl+Shift+L E` - 显示错误报告
- `Ctrl+Shift+L H` - 显示快捷键帮助

### 自定义配置

**快捷键配置**:
```json
{
  "live-code-viewer.createRoom": "ctrl+shift+l c",
  "live-code-viewer.showParticipantPanel": "ctrl+shift+l p",
  "live-code-viewer.showPerformancePanel": "ctrl+shift+l s"
}
```
