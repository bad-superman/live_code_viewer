## 🔥 核心模块设计

### RecordingManager - 会话录制管理器

**职责**:
- 管理会话录制生命周期
- 捕获协作编辑操作
- 处理录制元数据
- 控制录制状态

**接口**:
```typescript
interface RecordingManager {
  startRecording(sessionId: string): Promise<void>;
  stopRecording(): Promise<RecordingSession>;
  pauseRecording(): Promise<void>;
  resumeRecording(): Promise<void>;
  captureOperation(operation: EditOperation): void;
  getRecordingState(): RecordingState;
}
```

### PlaybackManager - 回放管理器

**职责**:
- 管理会话回放
- 控制播放速度和状态
- 处理时间轴导航
- 恢复编辑状态

**接口**:
```typescript
interface PlaybackManager {
  loadSession(sessionId: string): Promise<RecordingSession>;
  play(): Promise<void>;
  pause(): Promise<void>;
  seek(timestamp: number): Promise<void>;
  getPlaybackState(): PlaybackState;
  getTimeline(): Timeline;
}
```

### SessionStorage - 会话存储系统

**职责**:
- 存储录制会话数据
- 提供会话检索和查询
- 管理会话元数据
- 处理数据压缩和序列化

**接口**:
```typescript
interface SessionStorage {
  saveSession(session: RecordingSession): Promise<string>;
  loadSession(sessionId: string): Promise<RecordingSession>;
  listSessions(filter?: SessionFilter): Promise<SessionInfo[]>;
  deleteSession(sessionId: string): Promise<void>;
}
```

### TimelineController - 时间轴控制器

**职责**:
- 管理时间轴数据
- 处理时间轴事件
- 控制播放进度
- 提供时间轴导航

**接口**:
```typescript
interface TimelineController {
  createTimeline(operations: EditOperation[]): Timeline;
  getCurrentTime(): number;
  setCurrentTime(time: number): void;
  getTimelineEvents(): TimelineEvent[];
  navigateToEvent(eventId: string): void;
}
```

## 🔄 数据模型设计

### RecordingSession - 录制会话
```typescript
interface RecordingSession {
  id: string;
  title: string;
  description?: string;
  startTime: number;
  endTime: number;
  operations: EditOperation[];
  metadata: SessionMetadata;
  participants: ParticipantInfo[];
}
```

### EditOperation - 编辑操作
```typescript
interface EditOperation {
  id: string;
  timestamp: number;
  type: 'insert' | 'delete' | 'comment' | 'cursor';
  userId: string;
  data: any;
  position?: Position;
}
```

### Timeline - 时间轴
```typescript
interface Timeline {
  sessionId: string;
  duration: number;
  events: TimelineEvent[];
  markers: TimelineMarker[];
}
```
