3. **人工介入**: 发布操作可能需要人工认证和批准

### 发布脚本分析
```bash
# 关键代码片段 (来自scripts/publish-release.sh)
if [ -z "$VSCE_PAT" ] && [ -z "$VS_MARKETPLACE_TOKEN" ]; then
    echo "❌ 错误: 未配置 Personal Access Token (PAT)"
    echo "请访问: https://dev.azure.com/ 生成PAT"
fi
npx vsce publish --pat "$PAT"  # 需要PAT令牌
```

1. **PAT令牌生成**: 需要在Azure DevOps生成Personal Access Token
2. **权限配置**: PAT需要包含Marketplace (Publish)权限
3. **环境变量设置**: 需要设置`VSCE_PAT`或`VS_MARKETPLACE_TOKEN`环境变量
4. **命令执行**: 执行`npx vsce publish --pat "$PAT"`
