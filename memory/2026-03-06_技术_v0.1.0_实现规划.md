### 2. 多房间支持实现
**核心数据结构**:
```typescript
interface Room {
  id: string;
  name: string;
  type: 'public' | 'private' | 'invite-only';
  password?: string;
  participants: Participant[];
  host: string;
  createdAt: Date;
}

interface Participant {
  id: string;
  name: string;
  role: 'host' | 'viewer';
  joinedAt: Date;
}
```
