## 🎯 功能特性

### 多层安全防护
1. **客户端过滤** (观众端): 实时命令检查，即时用户反馈
2. **主机端验证** (主播端): 最终安全检查，防止绕过
3. **双重验证**: 客户端和主机端独立检查，提高安全性

### 智能命令分类
- **安全命令**: 白名单命令（ls, cd, cat等）
- **警告命令**: 需要用户确认的命令（sudo, rm -rf等）
- **危险命令**: 自动阻止的命令（rm -rf /, sudo su等）
- **未知命令**: 根据模式处理

### 可配置性
- **严格模式**: 只允许白名单命令
- **自定义规则**: 用户可添加危险/警告命令
- **安全命令扩展**: 可添加新的安全命令

### 用户体验
- **彩色终端反馈**: 使用ANSI颜色代码提供清晰反馈
- **详细原因说明**: 解释为什么命令被拒绝/警告
- **安全建议**: 提供替代方案或确认建议

## 🔧 技术实现

### 架构设计
```
观众端 (Viewer) → 命令过滤 → 安全检查信息 → 主机端 (Host) → 最终验证 → 终端执行
```

### 关键组件
1. **CommandFilter类**: 核心过滤逻辑，支持模式匹配和规则管理
2. **SecurityCheckInfo接口**: 标准化安全检查结果传递
3. **集成点**: 
   - `LiveCodePseudoterminal.handleInput()` (观众端)
   - `Host.handleTerminalInput()` (主机端)
   - `Host.performSecurityCheck()` (主机端验证)
