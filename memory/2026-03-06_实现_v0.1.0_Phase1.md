## 🏗️ 新的模块化架构

### 目录结构
```
src/
├── core/           # 核心业务逻辑
│   ├── connection-manager.ts
│   ├── room-manager.ts
│   └── permission-manager.ts
├── network/        # 网络通信
│   ├── websocket-client.ts
│   └── reconnect-manager.ts
├── ui/            # 用户界面 (待实现)
├── utils/         # 工具函数 (待实现)
└── extension.ts   # 扩展入口 (待重构)
```

### 设计原则
1. **单一职责**: 每个模块专注于特定功能
2. **事件驱动**: 通过事件进行模块间通信
3. **可测试性**: 模块化设计便于单元测试
4. **可扩展性**: 易于添加新功能

## 🔧 技术实现亮点

### 1. 连接稳定性
- **自动重连**: 网络断开时自动尝试重连
- **连接质量监控**: 实时评估网络质量
- **指数退避**: 智能的重连间隔控制

### 2. 多房间支持
- **房间隔离**: 每个房间独立管理
- **权限控制**: 基于房间类型的访问控制
- **状态持久化**: 房间配置本地存储

### 3. 权限系统
- **灵活的策略**: 支持公开/私有/邀请制房间
- **细粒度权限**: 查看/编辑/管理权限分离
- **自定义权限**: 支持用户级别的权限设置
